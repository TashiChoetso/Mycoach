# MVP and build order

## Phase 1 — now

Working: register, login, profile, catalog + custom areas, persist selections, Today shell personalized by name and areas.

## Phase 2

Goals, habits, tasks (CRUD + complete/skip + recurrence completions).

## Phase 3

Today dashboard with real tasks, habits, streaks, area list. Completion micro-interaction (“Nice work”).

## Phase 4

Scoring engine + `/scores/today` + Momentum on Today. Snapshot worker can wait until analytics.

## Phase 5

Analytics views: daily / weekly / monthly charts from snapshots + live queries.

## Later (not this ship)

6 Notifications · 7 Finance · 8 AI coach · 9 Pattern detection · 10 Personalization.

## Non-goals for MVP

Expo app, microservices, streaming chat, ML models, social/sharing, wearables.
